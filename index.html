About

My Background

I'm an R&D software engineer experienced in working at the intersection of code and hardware with real-time control systems and automated test suites. My background spans modernizing a legacy C# codebase for 5G over the air test chambers, writing Python test suites to validate SCPI command behavior, and diagnosing bugs from encoder drift to firmware incompatibilities.

I graduated Cum Laude from UC Santa Cruz with a degree in Computer Science. Before landing at Keysight Technologies, I built a dynamometer control application at Parker Hannifin, developed a plugin architecture for an open-source genomics pipeline tool, and helped visualize player behavior data at UCSC's Game User Interaction & Intelligence Research Lab.
